# 🐛 Debugging Exercises

Python and HTML exercises focused on debugging techniques and problem-solving with AI assistance.

## Files

| File | Description | Language |
|------|-------------|----------|
| `factorial.py` | Factorial computation (iterative) | Python |
| `factorial_recursive.py` | Factorial computation (recursive) | Python |
| `mines.py` | Minesweeper logic exercise | Python |
| `tic.py` | Tic-tac-toe game logic | Python |
| `checkbook.py` | Checkbook balancing utility | Python |
| `print_arguments.py` | Command-line argument printer | Python |
| `change_background.html` | Interactive background color changer | HTML |

## Usage

Run any Python exercise:

```bash
python3 factorial.py
python3 mines.py
python3 tic.py
```

Open the HTML file in a browser to test the interactive background changer.
