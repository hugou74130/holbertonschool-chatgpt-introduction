## 🧐 About <a name = "about"></a>

This repository contains exercises from the Holberton School ChatGPT introduction module. The goal is to learn how to effectively use AI tools for debugging, code explanation, and problem-solving.

## 🏁 Getting Started <a name = "getting_started"></a>

These instructions will get you a copy of the project up and running on your local machine.

### Prerequisites

- Python 3.8+
- A text editor or IDE

### Installing

Clone the repository:

```bash
git clone https://github.com/hugou74130/holbertonschool-chatgpt-introduction.git
cd holbertonschool-chatgpt-introduction
```

## 🔧 Running the tests <a name = "tests"></a>

Each script can be tested individually:

```bash
python3 debugging/factorial.py
python3 debugging/mines.py
python3 debugging/tic.py
```

## 🎈 Usage <a name = "usage"></a>

The `debugging/` directory contains several Python exercises:

- `factorial.py` — Factorial computation
- `factorial_recursive.py` — Recursive factorial
- `mines.py` — Minesweeper logic
- `tic.py` — Tic-tac-toe game
- `checkbook.py` — Checkbook balancing
- `print_arguments.py` — CLI argument handling
- `change_background.html` — Interactive HTML page
